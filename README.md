# ⚡ Code Runner G

Ek simple online code editor: HTML, CSS, JavaScript aur Python code likho, run karo aur tags seekho.

## Features
- Line numbers ke saath code space (neela background, laal text)
- HTML, CSS, JavaScript aur Python ke tabs
- Run button se turant output
- Tags button: har language ke tags ki table (code, kaise likhein, kaam, visual result)

## Kaise chalayein
1. `index.html` file ko browser mein kholo.
2. Koi tab chuno, code likho aur **Run** dabao.
3. Upar **Tags** button se tags ki jaankari dekho.
